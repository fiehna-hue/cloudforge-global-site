CloudForge Academy / Course track

AWS Cloud Security and DevSecOps

Apply threat modeling, IAM guardrails, encryption, detection, supply-chain security and incident response to AWS environments. Taught live online by a working engineer.

IAMKMSGuardDutyWAFSecurity Hub

Ask about this course See all five tracks

What you will learn

Securing AWS, step by step

Threat modeling

Map how a system could be attacked, and decide which risks to fix first.

IAM guardrails

Least-privilege roles, permission boundaries and policies that stop risky changes.

Encryption

Protect data at rest and in transit, with keys managed through KMS.

Detection

Spot trouble early with GuardDuty and Security Hub, and filter bad traffic with WAF.

Supply-chain security

Check what goes into your builds, so unsafe code and packages do not reach production.

Incident response

Contain and recover from an incident with an approved plan you have practised.

Where it fits

Part of the six-month programme

This track is taught in Month 5 of the full programme, security and resilience: supply-chain security, backup and recovery, and incident response. Earlier months cover AWS, Azure, infrastructure as code and delivery pipelines. Each track can also be taken on its own.

You finish with a capstone: defense in depth and incident response. You inject a misconfiguration, detect it, block the release and carry out an approved containment.
