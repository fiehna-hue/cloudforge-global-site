CloudForge Academy / Course track

DevSecOps: Automation, Delivery and Security

Build delivery workflows from Git and CI/CD through Terraform, Docker, Kubernetes, GitOps, observability and supply-chain security. Taught live online by a working engineer.

GitJenkinsGitHub ActionsTerraformDockerKubernetes

Ask about this course See all five tracks

What you will learn

From a commit to a secure release

Git and CI/CD

Build delivery pipelines with Git, Jenkins and GitHub Actions, with reviews before anything ships.

Infrastructure as code

Describe infrastructure with Terraform, so changes are repeatable and reviewable.

Containers

Package applications with Docker and run them on Kubernetes.

GitOps

Deploy from Git, so what is running matches what was approved.

Observability

See how a workload behaves, with dashboards and monitoring.

Supply-chain security

Check what goes into your builds, so unsafe code and packages do not reach production.

Where it fits

Part of the six-month programme

This track runs through the middle of the full programme. Month 3 covers Terraform, Ansible and CI/CD pipelines. Month 4 covers Docker, Kubernetes, Helm, GitOps and observability. Month 5 adds supply-chain security. Each track can also be taken on its own.

You finish with a capstone: an end-to-end secure delivery platform. You commit a change, pass the security gates, deploy through GitOps and roll back.

Account requirements and lab credits are confirmed for each batch. You get a cost-conscious lab plan and follow the budget and cleanup instructions.
