CloudForge Academy / Course track

AWS Solutions Architect Associate (SAA-C03)

Design secure, resilient and efficient AWS solutions across VPC, compute, storage, databases, serverless, monitoring and recovery. Taught live online by a working engineer.

VPCEC2S3RDSLambda

Ask about this course See all five tracks

What you will learn

Designing on AWS, step by step

Networking with VPC

Design subnets, routing and security controls so workloads are reachable only the way you intend.

Compute and storage

Choose between EC2, containers and serverless, and match storage to the workload with S3 and block storage.

Databases

Pick and run managed databases such as RDS, with backups and failover in mind.

Serverless

Build event-driven pieces with Lambda and understand when serverless is the right fit.

Monitoring

Watch what you build with metrics, logs and alarms, so problems are found early.

Recovery and resilience

Plan for failure with backups, multi-zone design and tested recovery steps.

01AWS architecture and account setup10 objectives · 4 topics

Objectives

  • Understand the AWS Well-Architected Framework and core architectural principles.
  • Design highly available, fault-tolerant, and scalable cloud infrastructure using AWS services.
  • Select the appropriate compute, storage, networking, and database services for given use cases.
  • Design secure applications using IAM, KMS, Security Groups, and VPC components.
  • Implement cost-optimized architectures using tools like AWS Pricing Calculator and Trusted Advisor.
  • Understand and design multi-tier, decoupled, and event-driven architectures using services like S3, Lambda, SNS, and SQS.
  • Use Auto Scaling, ELB, and CloudFront to improve application performance and availability.
  • Leverage CloudFormation and AWS CLI for infrastructure automation and repeatability.
  • Practice building and evaluating solutions that meet compliance, resilience, and operational excellence requirements.
  • Prepare for real-world scenarios with exam-aligned hands-on labs and mock assessments.

Where it fits

Part of the six-month programme

AWS runs through the first two months of the full programme: Month 1, foundations and AWS core services, and Month 2, AWS solution design with an Azure comparison. Linux, networking, Git and Python are taught first, so you don't need to arrive knowing them. Each track can also be taken on its own.

You finish with a capstone: a highly available three-tier application on AWS. You fail a web-tier instance, show the service recover, and explain the trade-offs.

Good to know

About the exam

This track is aligned to SAA-C03 preparation. It does not guarantee a pass or a job. Exam registration and certification are separate and handled by AWS.
